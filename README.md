# Madden Lite Prototype

A small browser-based football game inspired by the feel of modern Madden-style arcade gameplay.

## Features

- Simple top-down football field
- Run or pass plays
- Basic AI defenders
- Scoreboard and down/distance tracking
- Works directly in the browser with no build step

## Run it locally

Option 1: open `index.html` directly in a browser.

Option 2: serve the folder locally:

```bash
cd madden-lite
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Controls

- Move: WASD or Arrow Keys
- Sprint: Space
- Run play: R
- Pass play: P
- Reset game: Reset Game button

## Notes

This is a lightweight prototype, not a full Madden clone. It focuses on a playable arcade-style football experience in a browser.
